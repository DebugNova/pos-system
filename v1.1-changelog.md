# Suhashi POS V1.1 Changelog

Welcome to **Suhashi POS V1.1**! This update brings a massive set of improvements, focusing on iOS PWA stability, real-time synchronization, kitchen workflow automation, and subscription billing. 

Here is a comprehensive breakdown of everything added, changed, and fixed in this release.

## 🚀 Key Features & Enhancements

### 1. Order Management & Kitchen Workflow
* **Automated Kitchen Workflow**: Implemented an automated kitchen workflow to streamline order processing.
* **Supplementary Bills Management**: Added full visibility and editability for supplementary bills directly in the order edit flow.
* **Enhanced Item Customization**: Improved the way item modifiers and customizations are handled.

### 2. Real-Time Sync & iOS PWA Reliability
* **Aggressive Real-Time Tuning**: Significantly improved WebSocket health and real-time syncing for the iOS PWA experience.
* **Foreground Reconnection**: Added an absolute foreground reconnection and polling safety net to ensure the POS stays synced even on unreliable networks.
* **Mobile Sync Fixes**: Fixed live sync issues affecting billing, history, and reports on mobile devices, optimizing Supabase usage.

### 3. Subscription & Billing
* **Subscription UI & Reporting**: Enhanced subscription model reporting and polished the user interface.
* **Quarterly Plan Fixes**: Resolved an internal server error occurring during quarterly plan processing and improved API error logging.
* **Razorpay Integration**: Restored `total_count` to resolve a Razorpay validation error.

### 4. POS UI & Reporting
* **Awaiting Payment Filter**: Aligned the dashboard "awaiting payment" filter with the billing and sidebar for a consistent experience.
* **Pending Orders Count**: Fixed logic to correctly exclude cancelled and completed orders from pending counts.
* **Component Updates**: Broad updates to POS system components, dashboard, order history, print services, and underlying store logic.

### 5. Menu Updates
* **Item Renaming**: Renamed *Lemon Honey Tea* to *Lemon Ginger Tea*.
* **New Modifiers**: Added *Caramel* and *Hazelnut* modifiers to drinks.
* **Modifier Restrictions**: Restricted modifier options specifically for tea items to prevent invalid customizations.
